# DT Role Test Drive – Business Analyst (Clinic Operations)

Name: Kunapareddy Venkata Ramaiah  
Role: Business Analyst – Clinic Operations & Care Systems  

## Approach
This repository contains my Role Test Drive assignment for DeepThought CultureTech.

I approached both tasks by first understanding real clinic constraints:
- Manual systems
- Limited staff capacity
- Extremely limited doctor time
- High operational noise

The solutions focus on building simple, repeatable systems that:
- Catch errors early
- Reduce chaos
- Protect doctor attention
- Can realistically run inside a busy clinic

## Structure
- Task 1 focuses on daily inventory micro-audits
- Task 2 focuses on patient communication and follow-up control
- Assumptions and constraints are documented separately

All solutions are designed to be executable with existing clinic tools.
